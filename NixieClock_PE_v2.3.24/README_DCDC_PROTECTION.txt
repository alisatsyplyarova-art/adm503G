============================================================
NixieClock_PE_v2.1.1
Описание защиты DC/DC-преобразователя
============================================================

В проекте реализована программная защита высоковольтного DC/DC-преобразователя.
Защита управляет PWM генератора высокого напряжения и контролирует обратную
связь по входу A6 (AV_CTRL).

1. КОНТРОЛЬ ВЫСОКОГО НАПРЯЖЕНИЯ
--------------------------------
Вход A6 считывается командой:

    int voltage = analogRead(AV_CTRL);

A6 подключен к обратной связи высокого напряжения через резистивный делитель.
Arduino контролирует уменьшенный до безопасного уровня сигнал.

2. МАКСИМАЛЬНЫЙ PWM
--------------------
В программе установлен максимальный предел PWM:

    const uint8_t maxduty = 180;

Даже если начальное значение DUTY задано выше 180, фактический PWM не превысит
этот предел.

3. ЗАЩИТА ПРИ ВЫСОКОМ PWM И НИЗКОМ HV
--------------------------------------
Основные параметры:

    const uint8_t DCDC_PROTECT_DUTY = 175;
    const int DCDC_PROTECT_VOLTAGE = 350;
    const uint16_t DCDC_PROTECT_TIME_MS = 5000;

Защита контролирует ситуацию, когда PWM >= 175, а измеренный уровень A6 < 350.
Если это состояние сохраняется 5 секунд, DC/DC отключается:

    dcdcFault = true;
    setPWM(GEN, 0);
    r_duty = minduty;

Это предотвращает длительную работу преобразователя с большой мощностью,
когда высокое напряжение не достигает нормального уровня.

4. ЗАЩИТА ОТ ПЕРЕНАПРЯЖЕНИЯ
----------------------------
Порог:

    const int DCDC_OVERVOLTAGE = 700;

Если уровень A6 достигает 700 или выше и состояние сохраняется 100 мс,
DC/DC отключается:

    dcdcFault = true;
    setPWM(GEN, 0);
    r_duty = minduty;

5. ФИЛЬТРАЦИЯ КРАТКОВРЕМЕННЫХ АВАРИЙ
-------------------------------------
Защита не отключает DC/DC от одного кратковременного скачка.

Для низкого HV используется задержка 5 секунд.
Для перенапряжения используется задержка 100 мс.

Это позволяет не реагировать на обычные переходные процессы при запуске,
переключении ламп и изменении нагрузки.

6. ФИКСАЦИЯ АВАРИИ
-------------------
Защита работает в трёх состояниях (dcdcState):

    DCDCST_NORMAL  - всё в норме, обычная регулировка по обратной связи;
    DCDCST_WARNING - HV просело, но ещё в допустимых пределах: генератор
                     продолжает работать штатно, это лишь сигнал того,
                     что стоит присмотреться к нагрузке/делителю;
    DCDCST_FAULT   - авария: слишком низкое или слишком высокое HV.

Порог WARNING мягче порога FAULT и срабатывает раньше (PWM >= 165, A6 < 450,
дольше 2 секунд), но НЕ отключает генератор - меняется только состояние.

После перехода в FAULT:

    dcdcState = DCDCST_FAULT;
    setPWM(GEN, 0);
    r_duty = minduty;

при следующих вызовах DCDCTick() выполняется:

    if (dcdcState == DCDCST_FAULT) {
        setPWM(GEN, 0);
        return;
    }

То есть генератор остаётся выключенным и программа не выполняет бесконечные
повторные попытки запуска неисправного DC/DC - выйти из FAULT можно только
перезапуском/сбросом платы.

Текущее состояние можно посмотреть на шаге "DC-DC" стартового теста
(удержание кнопки "минус" при включении): 000 - NORMAL, 111 - WARNING,
999 - FAULT.

7. НОРМАЛЬНАЯ РЕГУЛИРОВКА
--------------------------
При отсутствии аварии используется обратная связь.
Номинальный уровень:

    const int nominallevel = 550;

Ошибка рассчитывается как:

    duty_delta = voltage - nominallevel;

Если напряжение выше требуемого, PWM уменьшается.
Если напряжение ниже требуемого, PWM увеличивается.
При этом превышение maxduty = 180 невозможно.

Схема работы:

    HV -> резистивный делитель -> A6 -> analogRead()
       -> регулятор -> PWM -> MOSFET -> DC/DC -> HV

8. ЧТО ЗАЩИЩАЕТ ТЕКУЩАЯ ПРОГРАММА
----------------------------------
- чрезмерную скважность PWM;
- длительную работу при большом PWM и низком HV;
- устойчивое перенапряжение;
- бесконечные повторные попытки запуска после аварии;
- выход PWM выше установленного программного предела.

9. ЧЕГО В ПРОЕКТЕ НЕТ
----------------------
В текущем коде нет непосредственного измерения тока катушки и нет датчика
температуры катушки.

Поэтому данная защита НЕ является полноценной аппаратной защитой от
превышения тока или перегрева.

Для полноценной защиты силовой части рекомендуется добавить:

- токовый шунт;
- компаратор/аппаратное ограничение тока;
- контроль температуры MOSFET и/или катушки;
- независимое аппаратное отключение DC/DC при аварии.

Аппаратная защита предпочтительнее, поскольку она способна отключить
преобразователь даже при зависании Arduino.

10. ОСНОВНЫЕ ПАРАМЕТРЫ
-----------------------
Номинальный уровень A6:                 550
Максимальный PWM:                       180
Порог защиты по PWM:                    175
Низкий уровень A6 при большом PWM:      < 350
Задержка низкого HV:                    5 с
Порог перенапряжения A6:                >= 700
Задержка перенапряжения:                100 мс
Минимальный PWM:                        10

Основная логика защиты находится в DCDC.ino.
Настройки порогов находятся в 0_data.ino.
